# Part 1 — Correct the Algorithm Enum API

The previous implementation incorrectly merged `to_str()` and `name()`.

We want **three separate functions** for good serialization practice.

This allows the enum to support:

* parsing
* serialization
* human-readable output

## Required API

Implement the following:

```
impl Algorithm {
    fn from_str(value: &str) -> Result<Self, String>

    fn to_str(&self) -> &'static str

    fn name(&self) -> &'static str
}
```

### Behavior

```
Algorithm::from_str("fcfs").unwrap().to_str() -> "fcfs"
Algorithm::from_str("sjf").unwrap().to_str() -> "sjf"
Algorithm::from_str("rr").unwrap().to_str() -> "rr"
```

Human readable names:

```
Algorithm::FCFS.name() -> "First-Come First-Served"
Algorithm::SJF.name()  -> "preemptive Shortest Job First"
Algorithm::RR.name()   -> "Round-Robin"
```

Important principle:

**`from_str()` and `to_str()` must be inverses.**
