# Testing
There are two directories for testing. `tests/human` is written by hand by us to ensure that ChatGPT's output is accurate and matches the output specification. `tests/ai` can be populated by ChatGPT for additional tests that it offers to write to check its own output. 

This offers some useful insight! Will any AI-made tests cover scenarios that were missed by the human-made tests? Were the AI tests accurate and rigorous or are they just for show? 

These tests will be automatically ran by a Github Actions script on push, allowing us to see the progression of passing more and more test cases (or beginning to plateau).
